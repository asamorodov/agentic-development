# Task package protocol: stage report in chat — 2026-06-16

Статус: выполнено.

## Изменение

В общий протокол упаковки добавлено правило: на каждой плановой остановке stage-stop пакет должен не только сохранить checkpoint-файл, но и вывести в чат краткое содержание checkpoint-а.

Если checkpoint не содержит вопроса, достаточно коротко показать, что сделано, какие главные файлы или архивы созданы, есть ли заметные риски и что будет следующим действием по умолчанию.

Если checkpoint содержит вопрос, вывод в чат дополнительно должен назвать главное сомнение, один вопрос пользователю и решение по умолчанию.

## Границы

Правило не добавляет вопросов в пакеты само по себе. Если в плане нет явной остановки и пользователь не задаёт staged mode, пакет собирается как раньше.
