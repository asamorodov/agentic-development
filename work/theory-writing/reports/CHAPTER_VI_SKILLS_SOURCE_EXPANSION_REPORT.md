# Chapter VI — skills source expansion report

## Что сделано

Раздел `Skills: повторяемые процедуры как часть проекта` расширен после дополнительного внешнего поиска. Правка сделана по интегрированной версии главы VI, а не как отдельный экспериментальный результат.

## Что добавлено

- больше фактуры о том, что представляет собой skill как повторяемая процедура;
- объяснение внутренней формы skill без привязки к конкретной раскладке Claude/Codex;
- роль краткого описания skill как механизма выбора, а не декоративной подписи;
- типовые сценарии использования: уточнение задачи, PRD, issues, TDD, архитектурное улучшение, handoff, диагностика, CI/Buildkite, PR review comments, release notes, merge conflicts, frontend/UI workflows;
- библиотечный слой: `openai/skills`, `anthropics/skills`, `awesome-claude-skills`, Agent Skills Library;
- риски: неверная фаза, слишком широкое описание, конфликтующие skills, устаревание, внешние непроверенные skills, действия с побочными эффектами, семантические атаки через `SKILL.md`.

## Что сознательно не добавлено

- подробные пути и способы установки skills;
- platform-specific packaging Claude/Codex;
- обзор рынка skills;
- длинный список marketplace-категорий;
- отдельный security-раздел.

## Проверка языка

Раздел переписан естественным русским техническим языком после добавления источников. Убраны англоязычные рабочие вставки вроде `release notes`, `inline comments`, `screenshot QA`, `supply-chain risk`, если они не являются именами источников или файлов.
