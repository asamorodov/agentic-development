# Отчёт — восстановление примера биллинга в главе IV

## Проблема

Предыдущая правка формально ввела пример биллинга, но оставила его слишком тонким. Фраза «нужно посчитать стоимость использования модели» не давала читателю достаточно материала, чтобы понимать последующие действия `reasons-canvas`, `generate`, `api-test`, `code-review`, `prompt-update` и `sync`.

## Что исправлено

Пример теперь задаёт предметную задачу внутри главы:

- API `POST /usage/quote`;
- входные поля: клиент, модель, входные и выходные токены;
- тарифный справочник, план клиента, квота, валюта и версия тарифа;
- правила для неизвестной модели, неизвестного клиента, отрицательных токенов, превышения квоты и округления;
- ожидаемую структуру реализации: контроллер, сервис расчёта, чтение тарифов, проверки входных данных;
- сценарии проверки;
- вопросы code review;
- различие между `prompt-update` и `sync` на этом же примере.

## Результат

Теперь пример не требует открытия внешней статьи для реконструкции хода SPDD. Внешняя ссылка остаётся источником, но не заменяет материал внутри главы.
