# Chapter VI — MCP source expansion report

Статус: выполнено после замечаний о недостаточном раскрытии MCP.

## Что изменено

- В главу добавлена отдельная подглава `MCP: управляемый доступ к внешнему миру`.
- MCP раскрыт как внешний канал чтения и действия, а не как общий список инструментов.
- Усилен тезис: для разных задач нужны разные MCP-серверы и разные границы доступа.
- Добавлены примеры серверов по классам задач: GitHub, Figma, Playwright, Chrome DevTools, Stripe, Notion, Sentry, Context7, reference servers Filesystem/Git/Fetch/Memory.
- Добавлен security-блок: tool exposure, human confirmation, scope minimization, tool poisoning, серверные ошибки, архитектурное ограничение доступа.
- Сохранена граница главы: не переносились transports, OAuth flow, JSON-RPC, установка серверов, полная threat model и runtime/sandbox детали.

## Проверка естественного русского

Изменённый участок написан как прямое объяснение механизма: что MCP меняет, какие классы серверов бывают, почему доступ должен быть узким и как MCP связан со skills и рабочим состоянием. Самокомментирующие формулы вида `для этой главы важно` и `пример показывает` в добавленном тексте не используются.
