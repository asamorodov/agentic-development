# Chapter VIII — GSD source deepening report

Date: 2026-06-15

## Reason

The integrated Chapter VIII already used GSD, but the GSD section was still relatively compressed compared with the atlas article and the GSD dossier. It covered the phase loop, `.planning/`, core artifacts and specialist agents, but did not transfer enough of the more concrete material that shows how GSD becomes a working process rather than a loose set of documents.

## Material added

The chapter now adds:

- GSD command/workflow routing from the User Guide: GSD does not always mean “run the full phase loop”; it chooses between workflow, project, quality, context, management and ideation paths.
- `gsd-pi` as the boundary case where process approach starts to touch execution environment: sessions, `.gsd/`, SQLite state, auto mode, deep planning, context preloading, tool policy, git isolation, supervision and forced verification.
- A stronger Verify/Ship distinction: verification is not a final statement of readiness; it must create usable grounds for stopping, continuing or returning state to the work graph.

## Boundaries preserved

The section still does not turn Chapter VIII into a separate GSD article. Details about sandbox, permissions, tool policy and runtime control are kept as a bridge to Chapter IX, not expanded as the main subject of Chapter VIII.
