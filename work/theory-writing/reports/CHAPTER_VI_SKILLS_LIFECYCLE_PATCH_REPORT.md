# Chapter VI — skills lifecycle patch report

## Что изменено

В главе VI расширен раздел о `skills`. Короткий блок из прежней версии заменён отдельной подглавой `Skills: повторяемые процедуры как часть проекта`.

Правка сделана по интегрированной версии главы VI в файловой системе. Цель — показать `skills` как один из центральных механизмов проектного интерфейса агента, а не как один пункт в каталоге инструментов.

## Содержательные изменения

Новая подглава объясняет:

- зачем нужен skill: повторяемая процедура перестаёт жить только в голове пользователя и последнем чате;
- что представляет собой skill изнутри без привязки к конкретной раскладке Claude/Codex: назначение, условия применения, порядок действий, входы, выходы, ограничения, поддерживающие материалы;
- жизненный цикл skill: повторяемая инструкция → черновик процедуры → использование → исправление по сбоям → уточнение описания и ограничений → включение в библиотеку → обновление или вывод из использования;
- роль библиотек skills: люди берут готовые процедуры, следят за новыми, адаптируют набор под свой стиль работы и проект;
- риски: неверная фаза, конфликт процедур, устаревание, скрытые решения и непроверенные внешние правила.

Текст написан без платформенной конкретики вроде того, куда именно положить файл и как назвать путь. Сохранены технические имена `skills`, `Codex`, `Claude Code`, `MCP`, но обычная проза остаётся русской.
