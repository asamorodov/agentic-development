
# Post-Atlas chapter list and scope map

Статус: рабочая карта границ глав, не новый Skeleton.  
Основание: Skeleton V5, `00_spine_map`, CORE plan и post-atlas source routing.

## Discovery profiles

- `D0` — внутренних материалов достаточно.
- `D1` — нужен короткий source-restoration для уже известных источников, ссылок, official docs или изображений.
- `D2` — внешний поиск нужен как содержательный материал.
- `D3` — нужен двухшаговый discovery/unfolding, потому что первичные источники могут открыть новые документы, термины, диаграммы и линии аргументации.

## Scope notes

- `APPENDIX` не является обычной главой для writing package. Это reference layer для завершённого Атласа.
- `INTRO` и `CONCLUSION` могут писаться после нескольких центральных глав, чтобы не стать пустой рамкой.
- Первые кандидаты на heavy chapter packages: III, VII, IX, XI или XII. Они дадут разные типы нагрузки: specification/ADR, PWG, runtime, evidence, authority.
- Глубокие узлы IV, VII и X должны быть написаны достаточно подробно, но без повторения всей соответствующей статьи Атласа.

## Open interpretation

Структура Skeleton V5 допускает, что VI и VII будут частично слиты при composition pass, если глава VI окажется слишком тонкой. Пока они оставлены отдельно, потому что VI отвечает за project context as interface, а VII — за долговечное состояние работы.
