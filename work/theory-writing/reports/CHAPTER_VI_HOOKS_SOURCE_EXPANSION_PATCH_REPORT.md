## Задача

Пользователь указал две проблемы:

1. Фраза `Эта техническая форма уточняет старую фразу «MCP даёт контекст»` разговаривала сама с собой внутри главы. Её нужно было не удалить, а переписать так, чтобы сохранить смысл.
2. Раздел про hooks нуждался во внешней фактуре и ссылках на источники. Нужно было усилить его релевантным материалом, прежде всего текущей практикой применения, не превращая главу в общий обзор безопасности среды выполнения.

## Что сделано

### MCP-абзац

Фраза переписана как прямое объяснение интерфейса MCP:

- `resources` дают данные, которые модель может прочитать;
- `prompts` дают рабочие сценарии или шаблоны сообщений;
- `tools` открывают действия с возможными побочными эффектами.

Смысл сохранён: MCP нельзя сводить к «контексту», потому что чтение resources и разрешение `tools/call` — разные типы доступа. Но глава больше не ссылается на собственную старую формулировку.

### Hooks-секция

Раздел `Где инструкция становится вмешательством` расширен. В текст добавлены внешние ссылки на официальные источники:

- Claude Code Hooks reference and guide;
- OpenAI Codex Hooks, Advanced Configuration and Slash Commands;
- Kiro Hooks, Hook types, Hook actions and examples;
- Google Developers Blog about Gemini CLI hooks and Gemini CLI hook-writing guide.

Новая структура раскрывает hooks как слой жизненного цикла:

1. Добавление контекста на `SessionStart` / `UserPromptSubmit`.
2. Барьер политики перед shell-командой, правкой файла или MCP tool.
3. Обратная связь после действия: форматирование, lint, тесты, security scan, обновление связанных файлов.
4. Финальный барьер `Stop` / `Agent Stop`, который не даёт завершить работу без обязательных проверок или обновления состояния.
5. Аудит и наблюдаемость: логирование вызовов инструментов, prompts, решений слоя разрешений и результатов проверок.

## Граница правки

Не разворачивался полный sandbox / approvals / threat model. Эти темы в главе названы следующим уровнем, чтобы hooks не затмили основную тему главы VI: проектный интерфейс и рабочее состояние агента.
