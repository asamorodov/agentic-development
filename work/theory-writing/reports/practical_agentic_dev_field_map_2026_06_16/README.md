# Practical agentic dev field map — imported research outputs

Дата импорта: 2026-06-16.

Эта папка сохраняет результат отдельного research-прохода `practical_agentic_dev_field_map_outputs.zip` как рабочее приложение к теоретическому труду.

Важно: файл `THEORY_CHANGE_DECISION.md` внутри исходного результата фиксировал осторожное решение «структурную ось труда не менять» и предлагал в основном локальные вставки. Последующее обсуждение уточнило это решение: корневая ось действительно остаётся прежней, но структура подачи должна измениться, чтобы современные источники не выглядели поздними заплатами. Актуальное уточнение зафиксировано в:

```text
work/theory-writing/reports/FIELD_MAP_STRUCTURAL_REVISION_PROPOSAL_2026_06_16.md
work/skeletons/THEORETICAL_SYNTHESIS_REBUILT_SKELETON_V6_FIELD_MAP_PROPOSAL.md
```

Исходные файлы из research-output сохраняются без нормализации языка и без переписывания. Их задача — быть приложенной фактурой и source map, а не готовой прозой для главы.
