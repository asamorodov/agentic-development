# Chapters VII–X — size and material-intake audit report

Date: 2026-06-15

## Result

The plans already contained a generic no-size-limit sentence and a weak-spots pass, but that was not strong enough. In practice, such wording can still let the executor stabilize around a familiar chapter size and treat late material intake as a small editorial repair.

The plans were updated to make the rule explicit: there is no target size, no normal length and no hidden 40K-like benchmark. Chapter size must come from source density, the number of necessary scenes, the complexity of the distinctions and the amount of relevant material that the chapter function requires.

## What changed

For all four plans, the general no-size-limit paragraph was strengthened. It now explicitly says that if meaningful sources, thin chapter-specific nodes or untransferred material from fragments, Atlas, dossiers or primary sources remain after the first draft, the executor must continue material intake and rewrite the affected sections.

The weak-spots pass in each plan was strengthened into an active material-intake pass. It now instructs the executor to reopen the relevant source families, not merely polish thin places.

## Per-chapter notes

- Chapter VII: active intake now points back to fragments, Atlas, dossier, source register and primary PWG/Beads/Gas Town materials when the graph, false done, claims/gates, evidence/source state or restoration remain thin.
- Chapter VIII: active intake now points back to GSD, BMAD, story/process material, Atlas, fragments and current-practice sources when the mode-of-continuation argument remains thin.
- Chapter IX: active intake now points back to runtime, permissions, sandbox/worktree/container, approvals, browser/devtools, tool calls and external service sources when the environment/rights distinctions remain thin.
- Chapter X: active intake now points back to Gas Town/Beads primary sources, Atlas, dossiers, local assets and stories when the multi-agent work environment remains too abstract.
