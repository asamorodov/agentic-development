# POST-ATLAS VISUAL LAYER BLUEPRINT AND PLANS UPDATE REPORT

Date: 2026-06-15

## Scope

Updated the post-Atlas per-chapter blueprint, the visual-assets protocol and target-group plans for chapters VII–XIII.

The change turns the old single-figure decision into a visual-layer pass:

- visual source discovery during external source reading;
- decision rule for `source_real_image` / `local_image_asset`, `external_real_image_candidate`, `source_backed_redraw`, `source_backed_synthetic_figure`, `synthetic_figure`, `defer` and `reject`;
- explicit distinction between real source images, source-backed redraws and synthetic explanatory diagrams;
- optional asset production when the environment can create SVG/PNG assets;
- fallback to visual briefs / figure candidates when the package cannot produce images;
- neutral image-generation prompt wording for MCP, hooks, permissions, sandbox and external-interface diagrams to reduce false refusals.

Plans for chapters I–VI were not changed. Chapters I–VI already have executed or current chapter outputs in this workflow; the requested update was applied only to the still-unwritten chapter plans VII–XIII.
