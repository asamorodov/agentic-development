Обновлён файл:

```text

```

Правка сделана после проверки схемы на плане и результате главы II.

Главные изменения:

1. В blueprint добавлено явное требование: после написания плана главы нужно выполнить отдельную русскую перепись самого плана.
2. Эта перепись не должна менять очередь проходов или добавлять новые требования. Её задача — убрать протокольный ритм, служебные кальки, искусственные рабочие термины, повторяющиеся страхующие формулы и фразы, похожие на готовые абзацы будущей главы.
3. Сам blueprint переписан естественным русским языком. Он сохранён как рабочий документ, но больше не должен звучать как старая машинная спецификация.
4. Сохранена логика главы II: короткая подготовка, первый черновик, русская перепись, содержательный добор, русская перепись после добора, решение по изображениям после устойчивого текста, проверка потерь и сопутствующих файлов.
5. Словарь смыслового перевода проверен: отдельная запись про `расследование` уже есть и остаётся активной.

## Практический смысл

Новые планы глав должны получаться ближе к обновлённому плану главы II: не с длинным языко-стилевым хвостом, а с нормальной очередью содержательной работы и короткими локальными напоминаниями о естественном русском языке.

Отдельная русская перепись самого плана нужна потому, что план становится исходным материалом для исполнительного пакета. Если план написан протокольным языком, этот язык легко просачивается в будущую главу.

## Проверки

- В blueprint есть отдельный раздел `Финальная русская перепись самого плана`.
- В критериях готовности плана есть требование пройти русскую перепись перед сборкой пакета.
- Старая схема `language pass / style pass / selective natural rewrite / guarded final style` не возвращена как активная очередь.
- В словаре смыслового перевода есть запись про `расследование`.
- Markdown code fences в изменённых `.md` файлах парные.
