# Chapter VI — subagents source expansion report

Статус: ручная правка интегрированной главы VI.

## Задача

Усилить раздел о `subagents` после дополнительного внешнего поиска и проверки параллелей в восстановленных историях. Цель — не сделать обзор multi-agent frameworks, а показать subagents как часть проектного интерфейса агента: отдельный контекст, отдельная роль, ограниченный набор инструментов, проверяемый выход и возвращение результата в общее состояние работы.

## Что изменено

- добавлена отдельная подглава `Subagents: разные исполнители для разных частей задачи`;
- объяснено, почему subagent нужен не потому, что «несколько агентов лучше одного», а потому что часть работы лучше вынести из основного контекста;
- раскрыта инженерная «роль» subagent: цель, область внимания, доступные инструменты, ограничения, формат ответа и критерии остановки;
- добавлены сценарии: исследование кодовой базы, security review, тестовый прогон, migration review, критика плана, параллельное PR review;
- добавлены элементы продвинутой оркестрации: разбиение задачи, границы подзадач, входные данные, инструментальные права, формат ответа, синтез и конфликт результатов;
- разведены обычные subagents, supervisor/router patterns и agent teams;
- добавлены риски: токены, дублирование, потеря общего контекста, несовместимые локальные предположения, конфликты при параллельной записи;
- добавлены параллели с историями Steinberger, Willison, Jökull Sólberg, Jesse Vincent и Mark Erikson.

Основные источники: OpenAI Codex Subagents, Claude Code Subagents и Agent SDK, Claude Code Agent Teams, Anthropic multi-agent research system, LangChain multi-agent docs, Cognition `Don’t Build Multi-Agents`, дизайн-обзор Claude Code.
