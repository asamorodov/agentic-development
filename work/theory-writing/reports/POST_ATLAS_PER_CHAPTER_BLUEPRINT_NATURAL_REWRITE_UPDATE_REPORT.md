# Обновление blueprint для планов отдельных глав

Дата: 2026-06-14.  
База: `git(12).zip` + текущий cumulative overlay с принятой главой II.  
Файл: `work/theory-writing/reports/POST_ATLAS_PER_CHAPTER_TARGET_PLAN_BLUEPRINT.md`.

## Что изменено

Blueprint переписан по схеме, проверенной на плане и новом результате главы II. Старый вариант сохранял послеатласное разделение global routing / per-chapter plan, но всё ещё предлагал хвост из отдельных языковых и стилевых проходов. После эксперимента с главой II эта схема признана менее удачной для глав: она слишком легко превращала письмо в протокольный ремонт.

Новый blueprint задаёт другую форму планов:

1. короткая рамка главы и границы с соседними главами;
2. рабочая модель предмета главы;
3. выбор внутренних материалов по функции;
4. внешний поиск только по реальным лакунам;
5. порядок объяснения без скрытого мини-черновика;
6. первый черновик без потолка объёма;
7. русская перепись после черновика;
8. интеграция фрагментов, историй, Атласа, досье и внешних источников;
9. русская перепись после каждого существенного добора;
10. добор слабых мест без искусственного ограничения размера;
11. проверка обзорности и замена каталогов сильными сценами или техническими опорами;
12. решение по фигуре после устойчивого текста, с балансом в сторону сохранения полезного визуального кандидата;
13. финальная проверка потерь, сопутствующих файлов и готовности.

В каждую инструкцию, где создаётся или правится текст, blueprint требует добавлять только короткий языковой якорь: `Пиши создаваемый текст естественным русским языком.` или `Переписывай текст естественным русским языком.` Подробные правила остаются в протоколах и словаре, а не копируются в каждый prompt.

## Что убрано

Для послеатласных глав больше не используется как базовая схема:

```text
language pass 1
language pass 2
style pass 1
style pass 2
style defect audit
selective natural rewrite
guarded final human technical style pass
```

Эти элементы могут встречаться в старых пакетах и исторических протоколах, но не должны возвращаться в новые планы глав.

## Проверка

Проверено:

- новый blueprint не содержит старой очереди как действующей схемы;
- в blueprint есть русская перепись после черновика и после содержательных интеграций;
- добор слабых мест сохраняется и явно не ограничивает размер заранее;
- визуальное решение стоит после устойчивого текста;
- словарь содержит отдельную запись про `расследование`;
- изменённые Markdown-файлы имеют парные code fences;
- overlay собирается в форме корня репозитория.
