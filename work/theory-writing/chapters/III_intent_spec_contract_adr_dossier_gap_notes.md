## Языковые риски

При следующих проходах отдельно проверить слова `свидетельство`, `доказательство`, `поверхность`, `архитектурная власть`, `контракт`, `Confirmation` и `статус`. Не заменять их автоматически. Для каждого случая нужно понять функцию фразы: это проверочный материал, основание для принятия, решение, правило для агента, ревью владельца или просто след сессии.


## Порядок удержания лакун

Лакуны закрываются по ходу объяснения, а не отдельным списком:

1. недостаток внешней формы намерения закрывается спецификацией;
2. недостаток проверяемости закрывается контрактом;
3. недостаток памяти решения закрывается ADR;
4. недостаток подтверждения закрывается только частично через `Confirmation`;
5. недостаток принятия остаётся для XII;
6. недостаток продолжимого рабочего состояния остаётся для VI–VII.


## Решение P12

Досье используются как gap-check и уточнение границ. В основной текст добавлена только одна ADR-связка: запись решения должна сохранять последствия, но не получать силу принятого правила без статуса. Остальные досье оставлены как фон для соседних глав.

## Решение P23

Проверка потерь по досье: обязательные для III лакуны закрыты. Глава объясняет недостаточность одной спецификации, наблюдаемую границу контракта, статус ADR, `Confirmation`, рабочую проекцию ADR и различение `origin/status`. Открытые темы явно переданы соседним главам и не требуют закрытия здесь.
