## Current use in public chapter

| Atlas item | Function in chapter | Detail level |
|---|---|---|
| SPDD / OpenSPDD | Shows intention, boundaries and prohibitions becoming an artifact before code. | One functional sentence; no REASONS Canvas field catalogue. |
| Spec Kit | Shows specification/design/tasks as a repo-carried transition from expected behavior to implementation. | One functional sentence; no workflow walkthrough. |
| Kiro | Shows spec/design/tasks as a product/IDE working surface. | Brief mention only. |
| BMAD | Shows process state, planning artifacts, story context, status, review and course correction. | Brief function-level mention; no persona/process guide. |
| HumanLayer | Shows harness/environment around agent beyond prompt text. | Brief functional anchor. |

## Excluded from chapter I

- Installation commands, directory trees, version details and exact CLI syntax.
- Screenshots and local SPDD images.
- Full comparison between methods.
- Claims about superiority or maturity ranking.

## Integration rule

Atlas material is used only to answer: **which layer of software change does this form make visible or durable?** Anything beyond that belongs to Atlas articles or later chapters.
