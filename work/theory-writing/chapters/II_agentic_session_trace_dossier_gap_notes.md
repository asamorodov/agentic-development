# II — заметки по лакунам досье

## Использовано

### Armin Ronacher

Досье оказалось полезным для технической конкретики: Makefile, локальные команды, логи, малый набор инструментов, Pi, деревья сессий, `/is`, `/wr`. Материал встроен в раздел о ближайшей причинности как пример минимальной исполнимой поверхности агента.

### Simon Willison

Материал по исследовательским задачам, Showboat/Rodney и риску прямого редактирования Markdown использован как главный эпизод для след сессии: маршрут ценен только тогда, когда он действительно связан с выполнением.

## Не использовано

### Product Migration Claude Code

Оставлено как возможный дополнительный пример, но не включено в основную главу. Для главы II пример создавал бы лишний поворот к миграционному кейсу и сильнее относился бы к будущим главам о проверке/критериях отказа.

### Quix / Klaus Kode

Не использовано: публичная опора слабее, а дополнительный пример не нужен для основной линии главы. Тема workflow engine уже покрыта точечно через различение слоёв среды и не требует отдельной истории.

## Риск

Лакун, блокирующих готовность главы, нет. Основной текст не требует скрытых досье для понимания ключевого тезиса. Риск перегруза историями сейчас выше риска недобора примеров.
