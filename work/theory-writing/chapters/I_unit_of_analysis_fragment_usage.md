# Chapter I fragment usage

Статус: синхронизация после P22.

## Main integrated fragments

| Fragment / input | Used in chapter | Integration status |
|---|---|---|
| `A1_change_not_prompt.md` | Core distinction: prompt / task / `diff` / session trace / software change; lifecycle axis; external carriers; trace vs durable state. | Integrated in main text, not left only in companion notes. |

| Post-Atlas routing reports | Chapter scope, source profile, story anchors, visual policy. | Reflected in pass reports and chapter-specific companions. |

## Not integrated by design

- Full A10 mode matrix: deferred to later mode-selection chapter / Fieldbook material.
- Full A1 story catalogue: not appropriate for chapter I.
- Full PWG / Beads mechanics: belongs to later durable-state chapter.
- Full evidence / authority mechanics: belongs to later evidence and governance chapters.

## Rule

No important fact needed to understand chapter I should remain only in the source fragments. Companion files may preserve provenance and deferred debt, but the public chapter must itself contain the central argument.
