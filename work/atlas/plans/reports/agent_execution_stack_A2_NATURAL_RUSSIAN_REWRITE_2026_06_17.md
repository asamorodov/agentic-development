## Языковые правки

Из плана убрана часть служебного английского слоя в обычной прозе. В рабочем тексте теперь используются более естественные варианты:

- `Target-group plan` → `план целевой группы`;
- `checkpoint` → `контрольная точка`;
- `stage stop` → `плановая остановка`;
- `synthesis design` → `проект сшивки статьи`;
- `open harnesses` → `открытые рабочие обвязки`;
- `agent-computer interface` → `интерфейс между агентом и компьютером`;
- `multi-agent orchestration` → `многоагентная координация`, где не требуется технический ярлык;
- `human-in-the-loop` → `участие человека в ходе выполнения`.

Имена файлов, URL, названия продуктов, устойчивые названия API и имена источников сохранены без искусственного перевода.
