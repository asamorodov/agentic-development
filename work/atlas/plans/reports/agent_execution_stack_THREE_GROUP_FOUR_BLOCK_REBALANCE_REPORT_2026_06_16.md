# A2 package rebalance report — 2026-06-16

Пакет A2 пересобирается по новой схеме: один executor package, три группы мини-досье и четвёртый завершающий блок для карты отношений, проекта сшивки, статьи и ремонтных проходов.

Причина изменения: предыдущий пакет содержал блоки в 50+ и 60+ рабочих листов; запуск показал, что такая длина ненадёжна. Новый вариант не убирает проход переписывания естественным русским языком. Вместо этого из каждого мини-досье убран один наименее самостоятельный сравнительный локальный угол, который лучше раскрывать позже в карте отношений.

Новая группировка мини-досье:

1. `06_open_harnesses_and_aci`, `09_observability_and_evaluation`, `10_durable_workflow_and_human_in_loop`.
2. `05_spec_driven_surfaces`, `07_graph_and_agent_runtimes`, `08_multi_agent_orchestration`.
3. `01_terminal_and_local_agents`, `02_ide_agents`, `03_cloud_issue_to_pr_agents`, `04_app_builder_surfaces`.

Смысловое качество сохраняется: языковые проходы оставлены, мини-досье остаются полноценными, а сравнительные вопросы переносятся в `agent_execution_stack_relationship_map.md` и итоговую сшивку статьи.
